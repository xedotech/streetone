# Street One

Free, open-source game. **One city street today. A city, PC, and consoles as the public fund grows.**

MIT. Community-owned. The game is not for sale — play it, fork it, donate if you want the next street.

The browser demo is a WebGL port of this same loop. **This folder is the canonical game.**

## Play

1. Install [Godot 4.3+](https://godotengine.org/download) (Forward+).
2. Import this folder as a project.
3. Press **F5**.

| Key | Action |
| --- | --- |
| **W / S** | Throttle / brake (in car). Walk (on foot) |
| **A / D** | Steer left / right from chase cam. Strafe on foot |
| **F** or **E** | Enter / exit the sedan |
| **Space** | Fire (on foot) |
| **R** | Restart after win / lose |

You spawn **in the car**, facing down the street. Drive, hop out, clear the shooters.

## Export

Editor → **Project → Export**. Linux/X11 and Web presets ship in `export_presets.cfg`. Native PC is the next funded milestone. Console targets need first-party licenses — they are a fund line, not a store listing.

## What’s in / what’s not

**In:** one street, arcade car, enter/exit, hitscan pistol, simple chase-and-shoot AI, win/lose.

**Not in yet:** a full city, native PC/console SKUs, multiplayer. See `OPEN-FUND.md`.

Donations go through [Bachs](https://bachs.io) on the public fund page. Forks are welcome.
